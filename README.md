# Nation of Last Land

Стратегическая RTS-игра с уникальной механикой временной перезагрузки в постапокалиптическом мире.

## О проекте

**Nation of Last Land** - это стратегическая RTS-игра в жанре tower defense, где игрок управляет фракцией антропоморфных котов. Ключевой элемент геймплея - **риск гибели аватара**: отправляя юниты на миссии, игрок рискует жизнью своего лидера SP1 "Excellent". Гибель приводит к временной перезагрузке мира - все достижения сбрасываются, кроме навыков аватара.

### Ключевые особенности
- **Уникальная механика перезагрузки** при гибели аватара
- **Антропоморфные коты** как экипаж механизированных машин
- **Модульная система устройств** для кастомизации машин
- **Вертикальное расширение баз** через систему этажей
- **Исследовательская система** с тремя типами научных данных
- **Глубокая система прогрессии** котов и предметов

## Технологии

- **Язык**: Rust
- **ECS**: hecs
- **Сериализация**: serde + YAML
- **Целевая платформа**: WebAssembly (веб)

## Структура проекта

```
src/
├── main.rs                 # Точка входа
├── game/                   # Основная логика игры
│   ├── mod.rs
│   ├── world.rs           # ECS мир
│   ├── systems/           # Системы ECS
│   └── components/        # Компоненты ECS
├── config/                 # Конфигурация
│   ├── mod.rs
│   └── units.yml          # Описания юнитов
├── api/                    # API для внешнего интерфейса
│   ├── mod.rs
│   ├── init.rs            # Инициализация игры
│   ├── create_vehicle.rs  # Создание юнитов
│   └── update.rs          # Игровой цикл
└── types/                  # Общие типы данных
    └── mod.rs
```
