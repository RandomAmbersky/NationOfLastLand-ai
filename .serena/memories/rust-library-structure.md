# Rust Library Structure

Проект open-entities - это Rust библиотека со следующей структурой:

```
open-entities/
├── Cargo.toml          # manifest file (в корне!)
├── src/
│   └── lib.rs          # основной код библиотеки
└── README.md
```

## Дополнительные команды

- `cargo test` - запуск тестов
- `cargo build` - сборка проекта
- `cargo doc --open` - генерация документации
