# Nation of Last Land - Концепция игры

## Общее описание

Стратегическая RTS-игра в жанре tower defense с элементами управления ресурсами. Игрок управляет базой выживания в постапокалиптическом мире через аватара SP1 "Excellent" - главного кота. Отправляя юниты на очистку территории от различных угроз, игрок рискует жизнью своего аватара. Гибель SP1 "Excellent" приводит к временной перезагрузке и возвращению в начало игры.

## Основные компоненты игры

### База (Base)
- Структуры для управления и поддержки юнитов
- Может быть размещено несколько баз на карте
- Каждая база генерирует ресурсы со временем
- Производит и ремонтирует юниты
- Может быть улучшена за репутацию
- Расширяется вертикально путем добавления этажей (FLOORS)

### Карта (Map)
- Двумерная карта с тайлами
- Случайная генерация событий (alerts)
- Возможность размещения нескольких баз на территории
- Юниты перемещаются по карте к целям
- Стратегическое планирование расположения баз для оптимального покрытия

### Юниты (Units)
- Механизированные машины с различными характеристиками
- Управляются и перевозятся человекоподобными котами
- Могут быть улучшены за репутацию
- Автоматически следуют к целям

## Геймплей механики

### Система событий (Alerts System)
- События появляются случайным образом на карте
- При приближении юнита событие "раскрывается"
- Раскрытие заменяет иконку события на группу юнитов

### Боевые механики
- Автоматическое столкновение юнитов
- Система типов урона и сопротивлений
- Различные эффекты от ликвидации юнитов
- **Управление машинами**: Каждая машина управляется котом-членом экипажа
  - Коты могут быть ранены или потеряны в бою
  - Коты испытывают усталость после длительных миссий
  - Опыт котов влияет на эффективность машин
  - Усталые коты работают менее эффективно
- **Риск гибели аватара**: SP1 "Excellent" может погибнуть в бою
  - Гибель приводит к временной перезагрузке игры
  - Игрок возвращается к началу с сохранением некоторых достижений
- **Сбор научной информации**: После уничтожения вражеских юнитов
  - Юниты автоматически собирают образцы и данные
  - Типы научной информации зависят от типа уничтоженного врага
  - Информация доставляется на базу для изучения

### Система ремонта
- Поврежденные юниты возвращаются на базу с пониженным HP
- FLOOR_REPAIR автоматически ремонтирует только юниты по возвращении
- Ремонт занимает время пропорционально степени повреждений
- Полностью восстанавливает HP юнитов

### Система лечения котов
- Раненые коты-члены экипажа нуждаются в специализированном лечении
- FLOOR_LAB_BIOLOGY предоставляет медицинские услуги для котов
- FLOOR_REST (комнаты отдыха) позволяют котам медленно восстанавливать здоровье
- Коты могут испытывать усталость после длительных миссий

### Система временной перезагрузки
- **Гибель SP1 "Excellent"**: Критическое игровое событие
  - Приводит к временной перезагрузке всего игрового мира
  - Игрок возвращается к началу игры, сохраняя только навыки SP1
  - Все остальные достижения, базы, ресурсы и открытия сбрасываются
- **Мотивация осторожности**: Игрок должен стратегически планировать миссии SP1
- **Риск vs Награда**: Участие SP1 в боях дает бонусы, но повышает ставки

### Управление несколькими базами
- **Размещение баз**: Возможность строительства новых баз на свободных тайлах
- **Распределение ресурсов**: Репутация - единый глобальный счетчик, доступный для всех баз
- **Логистика**: Юниты и коты-члены экипажа могут быть переназначены между базами
- **Перевозка персонала**: Коты могут перевозиться между базами на специальных транспортных машинах
- **Специализация**: Каждая база может быть оптимизирована под определенные функции
  - Базы с преимущественно FLOOR_REPAIR для восстановления
  - Базы с преимущественно обычными FLOORS для расширения парка
  - Смешанные базы для баланса
- **Зависимость от расстояния**: Эффективность может зависеть от расстояния до зоны операций

### Экономическая система
- **Сбор ресурсов**: Юниты могут собирать ресурсы с месторождений
- **Транспортировка**: Собранные ресурсы доставляются на базу
- **Хранение**: Ресурсы хранятся в FLOOR_STORAGE
- **Типы ресурсов**:
  - **Серебро**: Основной торговый ресурс
  - **Золото**: Премиум ресурс для дорогих улучшений
  - **Платина**: Редкий ресурс для уникальных предметов
- **Использование ресурсов**: Обмен на улучшения, новые юниты, специальные способности
- **Предметы (ITEMs)**: Одежда и аксессуары для котов
  - Создаются в FLOOR_LAB_TECHNOLOGY через крафт
  - Могут быть получены как награды за миссии
  - Обмениваются на ценные металлы

### Исследовательская система
- **Типы научной информации**:
  - **Биологические образцы**: От мутировавших существ, открывают улучшения здоровья и сопротивлений
  - **Технологические артефакты**: От рейдеров, улучшают боевые характеристики юнитов
  - **Экологические данные**: От токсичных зон, повышают эффективность против определенных угроз
- **Процесс исследования**: FLOOR_LABORATORY анализирует собранные образцы со временем
- **Результаты исследований**: Новые технологии, улучшения юнитов, специальные способности
- **Типы лабораторий**:
  - **FLOOR_LAB_BIOLOGY**: Специализируется на биологических образцах
    - Быстрее исследует биологические данные
    - Открывает улучшения здоровья и сопротивлений
    - Предоставляет медицинские услуги для лечения раненых котов
  - **FLOOR_LAB_TECHNOLOGY**: Специализируется на технологических артефактах
    - Быстрее исследует технологические данные
    - Открывает боевые улучшения и новые типы юнитов
    - Создает предметы экипировки (одежда, аксессуары, кольца)
    - Крафтит технологические устройства для котов
  - **FLOOR_LAB_ECOLOGY**: Специализируется на экологических данных
    - Быстрее исследует экологические данные
    - Открывает улучшения против специфических угроз
  - **FLOOR_LAB_UNIVERSAL**: Универсальная лаборатория (разблокируется после прогресса)
    - Может исследовать все типы данных
    - Более эффективна после специализации в нескольких областях
- **Прогрессия лабораторий**: После значительного прогресса в исследованиях нескольких типов данных игрок может разблокировать универсальную лабораторию

### Прогрессия
- **Репутация**: Основная валюта, зарабатывается за выполнение миссий
- **Ценные металлы**: Дополнительные ресурсы для продвинутых улучшений
  - Серебро: Средний уровень улучшений
  - Золото: Высокий уровень улучшений
  - Платина: Элитные и уникальные улучшения
- **Развитие котов**: Члены экипажа получают опыт и улучшаются
  - Повышение уровней и навыков
  - Разблокировка новых специализаций
  - Улучшение характеристик машин через опыт котов
  - **Экипировка предметами**: Коты могут экипироваться различными ITEM'ами
    - Улучшение характеристик через одежду и аксессуары
    - Разные типы предметов для разных слотов
    - Стратегический выбор из-за блокировок между предметами
- **Сохранение прогресса**: После временной перезагрузки сохраняются
  - Только прокачанные навыки SP1 "Excellent"
  - Все остальные достижения и прокачки сбрасываются
  - Базы, юниты, ресурсы и исследования начинаются заново
- Покупка новых юнитов
- Улучшение существующих юнитов
- Расширение базы и строительство новых баз

### Система предметов (ITEMs)
- **Типы предметов**: Одежда и аксессуары для котов
  - **Шлем**: Головной убор, защита головы
  - **Очки**: Защитные очки, улучшение зрения
  - **Наушники**: Аудио-устройства, улучшение слуха
  - **Наплечники**: Защита плеч и верхней части спины
  - **Бронежилет**: Основная защита торса
  - **Нарукавники**: Защита предплечий
  - **Перчатки**: Защита рук
  - **Штаны**: Защита нижней части тела
  - **Ботинки**: Защита ног и ступней
- **Кольца**: Аксессуары для пальцев (по 3 кольца на каждый палец кота)
  - Магические кольца с различными эффектами
  - Уникальные способности и бонусы
- **Серии предметов**: Предметы делятся на 3 серии (уровня качества)
  - Серия 1: Базовые предметы
  - Серия 2: Улучшенные предметы
  - Серия 3: Элитные предметы
- **Источники предметов**: Получение через исследования, награды, крафт
- **Эффекты предметов**: Улучшение характеристик котов и их машин
- **Блокировки слотов**: Некоторые предметы конфликтуют друг с другом
  - **Шлем** блокирует **очки** и **наушники** (комплексная защита головы)
  - **Бронежилет** блокирует **наплечники**, **нарукавники** и **перчатки** (интегрированная защита)
  - Игрок должен выбирать между универсальными и специализированными предметами

## Типы юнитов

### Игровые юниты (Player Units)

#### Машины (Vehicles)
- **Scout Car**: Быстрый разведчик, низкий HP, высокая скорость
- **Armored Truck**: Бронированная машина, высокий HP, средняя скорость
- **Heavy Tank**: Тяжелый танк, максимальный HP, низкая скорость

#### Человекоподобные коты (Anthropomorphic Cats)
- **SP1 "Excellent"**: Главный кот - аватар игрока
  - Уникальный персонаж с повышенными характеристиками
  - Символизирует лидера фракции
  - Его гибель приводит к временной перезагрузке игры
  - Не может быть заменен или клонирован
  - Сохраняет прокачанные навыки после временной перезагрузки
- **Crew Members**: Управляют машинами, могут перевозиться между базами
- **Specialists**: Коты с уникальными способностями и характеристиками
  - Разные специализации (разведка, ремонт, сбор ресурсов)
  - Могут получать опыт и улучшаться
  - Имеют индивидуальные черты характера

### Враждебные юниты (Enemy Units)
- **Trash Piles**: Мусорные кучи, низкий HP, не атакуют
- **Toxic Waste**: Ядовитые лужи, наносят ACID урон при ликвидации
- **Mutant Creatures**: Мутационные существа, активная атака
- **Raiders**: Рейдеры на машинах, высокая мобильность

### Нейтральные/Союзные юниты (Neutral/Ally Units)
- **Survivors**: Выжившие, могут быть спасены для бонуса репутации
- **Wandering Traders**: Торговцы, продают редкие улучшения

## Типы событий (Alerts)

### Trash Alert
- **Описание**: Обычный мусор на дороге
- **Раскрытие**: 1-3 мусорных кучи
- **Награда**: Низкая репутация
- **Особенности**: Безопасное событие для новичков

### Waste Alert
- **Описание**: Загрязнение окружающей среды
- **Раскрытие**: 1-2 ядовитых лужи
- **Награда**: Средняя репутация
- **Особенности**: Наносит ACID урон при ликвидации

### Mutant Alert
- **Описание**: Активность мутировавших существ
- **Раскрытие**: 2-4 мутантных существ
- **Награда**: Высокая репутация
- **Особенности**: Активная атака, повышенная опасность

### Survivor Alert
- **Описание**: Сигнал бедствия от выживших
- **Раскрытие**: Группа выживших + возможные враги
- **Награда**: Высокая репутация + бонусы
- **Особенности**: Временное событие, требует быстрого реагирования

### Resource Alert
- **Описание**: Месторождение ценных металлов (серебро, золото, платина)
- **Раскрытие**: Месторождение с определенным количеством ресурса
- **Награда**: Ценные металлы + репутация
- **Особенности**: Требует сбора и транспортировки на базу
  - **Серебро**: Базовый ценный ресурс, средняя ценность
  - **Золото**: Высокая ценность, редкий ресурс
  - **Платина**: Максимальная ценность, очень редкий ресурс

## Система улучшений

### Улучшения юнитов
- **Скорость движения**: Увеличивает мобильность
- **Здоровье (HP)**: Увеличивает живучесть
- **Сопротивление урону**: Снижает урон от конкретных типов
  - Physical (физический)
  - Acid (кислотный)
  - Radiation (радиационный)
  - Fire (огненный)

### Улучшения базы
- **Генерация ресурсов**: Увеличивает доход репутации
- **Скорость производства**: Ускоряет создание юнитов
- **Максимум юнитов**: Увеличивает лимит одновременных юнитов
- **Строительство новых баз**: Возможность размещения дополнительных баз на карте
- **Улучшения FLOOR_REPAIR**: Прокачки скорости ремонта юнитов
- **Улучшения FLOOR_LABORATORY**: Прокачки скорости и эффективности исследований
  - Специализация лабораторий по типам научной информации
  - Переход к универсальным лабораториям
- **Улучшения FLOOR_REST**: Ускорение восстановления котов и снижение усталости
- **Улучшения FLOOR_LAB_TECHNOLOGY**: Повышение качества крафта предметов и скорости исследований

#### Система этажей (FLOORS)
- **FLOOR_COMMON**: Увеличивают вместимость базы для размещения юнитов
- **FLOOR_REPAIR**: Специализированный этаж с ремонтными мощностями
  - Автоматически ремонтирует поврежденные юниты по возвращении с миссий
  - Восстанавливает HP до максимального значения
  - Требует времени на ремонт каждого юнита
  - **Прокачки**: Возможность улучшения скорости ремонта
    - Увеличение скорости восстановления HP
    - Снижение времени ремонта юнитов
    - Возможность одновременного ремонта нескольких юнитов
- **FLOOR_STORAGE**: Склад для хранения собранных ресурсов
  - Хранит серебро, золото, платину
  - Увеличивает вместимость хранилища
  - Защищает ресурсы от потери при атаках на базу
- **FLOOR_LABORATORY**: Семейство лабораторий для изучения научной информации
  - **Специализированные лаборатории**: FLOOR_LAB_BIOLOGY, FLOOR_LAB_TECHNOLOGY, FLOOR_LAB_ECOLOGY
  - **Универсальная лаборатория**: FLOOR_LAB_UNIVERSAL (разблокируется после прогресса)
  - Анализирует данные, собранные после уничтожения врагов
  - Открывает новые технологии и улучшения
  - Требует времени на исследование каждого образца
  - **Прокачки**: Увеличение скорости исследований и эффективности анализа
- **FLOOR_REST**: Комнаты отдыха для восстановления котов
  - Снижает уровень усталости после миссий
  - Улучшает моральный дух и эффективность котов
  - Может быть улучшен для более быстрого восстановления

## Техническая архитектура

### Основной стек технологий
- **Язык**: Rust
- **ECS**: hecs
- **Сериализация**: serde с поддержкой YAML
- **Сборка**: WebAssembly для веб-версии

### Структура проекта
```
src/
├── main.rs                 # Точка входа
├── game/                   # Основная логика игры
│   ├── mod.rs
│   ├── world.rs           # ECS мир
│   ├── systems/           # Системы ECS
│   └── components/        # Компоненты ECS
├── config/                 # Конфигурация
│   ├── mod.rs
│   └── units.yml          # Описания юнитов
├── api/                    # API для внешнего интерфейса
│   ├── mod.rs
│   ├── init.rs            # Инициализация игры
│   ├── create_vehicle.rs  # Создание юнитов
│   └── update.rs          # Игровой цикл
└── types/                  # Общие типы данных
    └── mod.rs
```

### API интерфейс
```rust
// Инициализация игры
fn init() -> String // JSON с начальным состоянием

// Создание юнита
fn create_vehicle(type: &str, position: (f32, f32)) -> String // JSON с ID юнита

// Игровой цикл
fn update(dt: f32) -> String // JSON с обновленным состоянием мира
```

### Формат данных
- **Конфигурация**: YAML файлы для описания юнитов, событий, улучшений
- **Состояние игры**: JSON для коммуникации с внешним интерфейсом
- **ECS компоненты**: Внутренние структуры данных для логики игры

### Ключевые системы
- **Movement System**: Перемещение юнитов
- **Combat System**: Боевые взаимодействия
- **Alert System**: Генерация и обработка событий
- **Resource System**: Управление репутацией и ресурсами
- **Upgrade System**: Система улучшений
