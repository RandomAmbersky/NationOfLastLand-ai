Demo Features

  • WebAssembly Backend: Game logic runs in Rust compiled to WebAssembly
  • Pixi.js Rendering: Real-time graphics rendering using Pixi.js
  • Entity Management: ECS-based entity system with position components
  • Live Updates: Real-time synchronization between Rust and JavaScript
  • Movement System: Click entities to select them, then click map to set movement targets
  • Real-time Movement: Entities move smoothly toward their targets at different speeds

How to Use

  1. Click "Initialize Game" to start
  2. Click "Spawn Vehicle" to create units
  3. Click on a vehicle to select it (yellow ring appears)
  4. Click on another vehicle to switch selection
  5. Click anywhere on the map to set a movement target (red cross appears)
  6. Use "Clear Selection" to deselect current unit
  7. Watch the vehicles move toward their targets!
