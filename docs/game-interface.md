## Ключевые элементы дизайна

### **Цветовая схема**
- **Фон карты**: Темно-серый постапокалиптический ландшафт
- **Базы игрока**: Синий (#2563eb) с градиентами
- **Вражеские юниты**: Красный (#dc2626) для угрозы
- **События**: Оранжевый (#ea580c) для предупреждений
- **SP1 Excellent**: Золотой (#fbbf24) для уникальности
- **Ресурсы**: Зеленый (#16a34a) для положительных элементов

### **Стиль элементов**
- **Иконки**: Пиксель-арт стиль в духе классических стратегий
- **Шрифты**: Моноширинный для технических данных, sans-serif для описаний
- **Анимации**: Плавные переходы, пульсирующие индикаторы риска
- **Звуки**: Тихие UI звуки, тревожные сигналы для опасных событий

### **Адаптивность**
- **Десктоп**: Полноценный интерфейс со всеми панелями
- **Мобильные**: Сворачиваемые панели, тач-контролы
- **Веб**: Оптимизация под браузерные ограничения

Этот интерфейс подчеркивает стратегическую глубину игры, риск потери прогресса и тактическое управление ресурсами, сохраняя при этом доступность для новых игроков.
