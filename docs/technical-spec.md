# Nation of Last Land - Technical Specification

## Основной стек технологий

- **Язык**: Rust
- **ECS**: hecs
- **Сериализация**: serde с поддержкой YAML
- **Сборка**: WebAssembly для веб-версии

## Структура проекта

```
src/
├── main.rs                 # Точка входа
├── game/                   # Основная логика игры
│   ├── mod.rs
│   ├── world.rs           # ECS мир
│   ├── systems/           # Системы ECS
│   └── components/        # Компоненты ECS
├── config/                 # Конфигурация
│   ├── mod.rs
│   └── units.yml          # Описания юнитов
├── api/                    # API для внешнего интерфейса
│   ├── mod.rs
│   ├── init.rs            # Инициализация игры
│   ├── create_vehicle.rs  # Создание юнитов
│   └── update.rs          # Игровой цикл
└── types/                  # Общие типы данных
    └── mod.rs
```

## API интерфейс

```rust
// Инициализация игры
fn init() -> String // JSON с начальным состоянием

// Создание юнита
fn create_vehicle(type: &str, position: (f32, f32)) -> String // JSON с ID юнита

// Игровой цикл
fn update(dt: f32) -> String // JSON с обновленным состоянием мира
```

## Формат данных

- **Конфигурация**: YAML файлы для описания юнитов, событий, улучшений
- **Состояние игры**: JSON для коммуникации с внешним интерфейсом
- **ECS компоненты**: Внутренние структуры данных для логики игры

## Ключевые системы

### Movement System
- Перемещение юнитов по карте
- Путьfinding и навигация
- Оптимизация производительности для больших количеств юнитов

### Combat System
- Боевые взаимодействия между юнитами
- Расчет урона с учетом типов и сопротивлений
- Эффекты от уничтожения юнитов

### Alert System
- Генерация и обработка случайных событий
- Раскрытие иконок событий
- Управление таймерами и триггерами

### Resource System
- Управление репутацией и ресурсами
- Сбор, транспортировка и хранение
- Экономический баланс

### Upgrade System
- Система улучшений юнитов и баз
- Прогрессия и разблокировка контента
- Баланс стоимости и преимуществ

## Архитектурные решения

### ECS паттерн
Использование Entity Component System для:
- Гибкого управления игровыми объектами
- Оптимизации производительности
- Легкого расширения функциональности

### WebAssembly
- Кросс-платформенная совместимость
- Высокая производительность
- Защита исходного кода

### YAML конфигурация
- Человекочитаемые файлы конфигурации
- Легкое изменение баланса
- Валидация данных

## Производительность

### Оптимизации
- Эффективное использование ECS
- Минимизация аллокаций в игровом цикле
- Кэширование часто используемых данных

### Масштабируемость
- Поддержка большого количества юнитов
- Эффективная работа с большими картами
- Оптимизация для мобильных устройств

## Безопасность и надежность

### Обработка ошибок
- Graceful degradation при ошибках
- Валидация входных данных
- Logging для отладки

### Тестирование
- Unit тесты для основных систем
- Integration тесты для API
- Performance benchmarks
